# Specifications

Tendril follows these documents, and its comments cite them by name, version,
and section.

## USB

- Universal Serial Bus Specification, Revision 2.0, with its errata, the
  Interface Association Descriptor ECN, the Link Power Management ECN, and the
  connect timing ECN.
- Universal Serial Bus 3.2 Specification, Revision 1.1.

## Host controllers

- Intel eXtensible Host Controller Interface for Universal Serial Bus (xHCI),
  Revision 1.2.
- Intel Enhanced Host Controller Interface Specification for Universal Serial
  Bus (EHCI), Revision 1.0.
- OpenHCI Open Host Controller Interface Specification for USB, Release 1.0a.
- Intel Universal Host Controller Interface (UHCI) Design Guide, Revision 1.1.

## PCI

- PCI Local Bus Specification, Revision 3.0.

## Device classes

- Device Class Definition for Human Interface Devices (HID), Version 1.11; HID
  Usage Tables, Version 1.7.
- USB Mass Storage Class Bulk-Only Transport, Revision 1.0; Control/Bulk/
  Interrupt (CBI) Transport, Revision 1.1; UFI Command Specification, Revision
  1.0; USB Attached SCSI Protocol (UASP), Revision 1.0.
- USB Class Definitions for Communications Devices, Revision 1.2 with errata
  and ECNs through April 3, 2025; CDC PSTN Subclass, Revision 1.2; CDC ECM
  Subclass, Revision 1.2; CDC NCM Subclass, Revision 1.0 (Errata 1).
- Microsoft [MS-RNDIS]: Remote Network Driver Interface Specification (RNDIS)
  Protocol, v20130118 (revision 1.0).

## Devices and chipsets

- Silicon Labs AN571, Revision 0.4 (CP210x).
- FTDI AN232B-04, Version 1.1, AN232B-05, and AN_120, Version 1.2.
- Intel 82371AB (PIIX4) datasheet 290562; Intel 9 Series Chipset Family PCH
  datasheet 330550-002.
